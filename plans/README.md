## Findings considered and rejected

- Removing the admin preview entirely was rejected because the mobile app
  currently needs it to test the admin experience in development.
- Treating the nullable fields in `UpdatePlaceCurationDto` as broken validation
  was rejected because `@IsOptional()` already skips subsequent validators for
  `null` and `undefined`.
- The current Multer advisory was not promoted to a reachable vulnerability:
  the package is transitively installed, but the audited API exposes no
  multipart upload endpoint. Dependency maintenance remains reasonable, but it
  is not part of Plan 001.
